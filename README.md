# Database Testing with Mockito and JUnit4

*A Spring Boot project demonstrating service-layer testing with mocked database dependencies*

### Technologies

- *Java 25*
- *Spring Boot*
- *JUnit 4*
- *Mockito*
- *Spring Data JPA*
- *Maven*

### Testing scope

- *Mocking repository dependencies with @Mock*
- *Injecting mocks into services with @InjectMocks*
- *Testing business rules and validation*
- *Verifying repository interactions*
- *Testing error handling and exceptions*
